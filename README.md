# narabekae（英語 並べ替え問題）

高校1年生向けの英語並べ替え問題のWebページです。

- バラバラの単語カードをタップして正しい順番に並べ、「答え合わせ」で正解・不正解を表示します
- 並べたカードをタップすると元に戻せます。不正解のときは「もう一度」または「正解を見る」を選べます
- 10問終わると結果（1回目の答え合わせで正解した数）と一覧を表示し、「まちがえた問題だけ」解き直せます
- スマホ対応。個人情報（名前など）は扱わず、データの保存や送信もしません

## 使い方

`index.html` をブラウザで開くだけで動きます（`index.html` と `questions.js` を同じフォルダに置いてください）。
GitHub Pages で公開する場合は、リポジトリの Settings → Pages でこのブランチのルートを指定します。

## 問題の差し替え

`questions.js` だけを編集します。1問は次の形です。

```js
{
  ja: "私は毎朝7時に起きます。",                                   // 日本語の意味
  words: ["I", "get", "up", "at", "seven", "every", "morning"],   // 正しい順番の単語
  end: ".",                                                       // 文末の記号（カードにしない）
  // alt: [[...]],   // 別の正解の並び順があるときだけ（任意）
},
```

問題数は `questions.js` に書いた数に自動で合わせます。
